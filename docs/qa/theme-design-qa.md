# 设计 QA 报告

## Issue #13：首页信息架构与发现层级

### 第一性原理结论

首页每个保留区域只承担一个独立任务：

| 顺序 | 区域 | Visitor 此刻要完成的任务 |
| --- | --- | --- |
| 1 | 品牌主视觉 | 理解品牌提供什么，以及为什么值得继续看 |
| 2 | 入门作品 | 用较低风险选择第一件想完成的作品 |
| 3 | 当季推荐 | 获得“现在适合做什么”的灵感 |
| 4 | 作品与材料发现 | 主动搜索、筛选和比较 Product |
| 5 | 选择前帮助 | 在仍不确定时进入真实可用的联系路径 |

- 原“三种选购路径”分别重复 Hero 次 CTA、入门作品 / 商品筛选与帮助区，没有独立任务，已从首页模板移除；Section 文件保留，便于回滚或在其他页面复用。
- 当季推荐移动到完整商品网格之前，并直接进入当前语言首页的秋冬筛选结果，先给灵感，再让 Visitor 做高成本比较。
- LINE 链接未配置时，不再显示不可用的 LINE 按钮；帮助区只提供真实联系页入口。未来配置 LINE 后仍恢复原有 LINE 文案与主按钮。
- 中文首页主内容末端从约 5280 px 收敛到 4136 px，减少约 21.7%，同时保留品牌、作品、季节、完整发现和帮助五项能力。

### Findings 与修复

- [P1] 手机端三项承诺的主文案仅 11 px、补充文案仅 9.2 px，重要价值信息难以扫读。
  - 修复：手机端只保留三项可独立理解的主承诺，将字号统一为 12 px；Desktop 保留完整解释。
- [P1] 首页商品网格中的毛线、Project Kit、成品、工具与礼盒没有可见角色区别，Visitor 只能依赖长标题猜测。
  - 修复：从 Shopify Product tags 读取既有商品角色，在首页发现卡片中加入日 / 中 / 英本地化角色标签；不修改 Product、Variant、价格或库存。
- [P2] 手机端五个筛选项需要横向滑动，但右侧没有继续浏览提示，且 38 px 控件高度偏小。
  - 修复：为筛选轨道增加右侧渐隐箭头，将点击高度提高到 44 px；滑到末端后箭头自动消失。

### 交互与回归

- 中文“编织套装 + 包袋”组合筛选命中 2 件商品，角色标签均为“编织套装”；搜索“蛋糕线”命中 2 件。
- 浏览器前进 / 后退可恢复搜索和筛选状态；商品卡片可进入详情页，返回后发现区仍可用。
- 日文、简体中文、英文均按相同五段顺序渲染，无“三种选购路径”，页面横向溢出均为 0。
- 当季 CTA 保持当前语言路径，进入 `cold` 筛选并滚动到发现区。
- 未配置 LINE 时三种语言都只显示一个真实 Contact 链接，不出现 `href="#"` 的伪操作。
- Desktop 初始展示 8 件商品，首行 4 张卡片宽高一致，没有新增布局跳动。
- `npm run verify`、`node --check assets/yarn-discovery.js` 与 `git diff --check` 通过；Theme Check 保留基线已有的 8 条 warning，本次无新增 warning。
- 未发布到 production，未提交真实订单，未修改 Shopify 运营数据。

本轮结果：passed。

## 比较历史

### 第 1 轮

- [P1] 全站黑白/深色编辑感与 Hoshiami 的柔软清新审美明显偏离。
- [P1] 首页“按目的购买”使用抽象视觉，缺少真实作品图驱动。
- [P2] 移动首屏文字直接叠在复杂图片上，阅读性和层级不足。
- 修复：重建五色浅色令牌、字标、按钮、标签、商品卡片和页面背景；目的入口改为真实商品图；移动首屏改为浅蓝文字区与图片上下分层。
- 复核证据：`home-desktop-pass1.png`、`home-mobile-pass3.png`、`purpose-desktop-pass1.png`、`purpose-mobile-pass1.png`。

### 第 2 轮

- [P2] 商品媒体轮播在部分加载时收到缺少当前元素的事件并输出脚本错误。
- 修复：在 `onSlideChanged`、缩略图移动和活动缩略图读取处增加空值判断。
- 复核证据：新访客商品页重新加载后不再出现媒体轮播错误，商品图片、27 个变体和加购按钮保持可用。

### 第 3 轮

- [P1] 公开访客预览中的语言菜单提交后仍停留在原语言，中文和英文无法通过菜单进入。
- 根因：隐藏字段使用了 Shopify 不识别的 `locale_code`，且访客预览域名上的本地化表单提交没有产生可持续的语言路径变化。
- 修复：字段改为官方要求的 `language_code`；语言选项同时输出真实本地化 URL，脚本在存在真实 URL 时使用原生导航，并保留首页之外的当前页面路径。
- 复核：桌面首页已连续通过日→英→中→日；390 × 844 移动视口下，`/ja/products/puni-yarn` 已通过抽屉切换到 `/zh-cn/products/puni-yarn`，页面语言与商品正文同步变为简体中文。

### 第 4 轮

- [P1] 中文移动首页主按钮与下方主图零间距，视觉上形成重叠；简体中文错误沿用 Murecho 日文字体。
- 根因：通用 `.page-width` 内边距覆盖了主视觉的移动端上下内边距；全站字体变量没有按页面语言区分中文字体。
- 修复：提高主视觉移动端内容规则的优先级，恢复 30 px 顶部和 32 px 底部内边距；为 `zh-CN` 增加系统简体中文字体栈与中文字距设置。
- 复核：同状态并排比较确认按钮与图片分离；动画完成后的实测间距为 32 px。日、中、英移动首页横向溢出均为 0，中文主按钮可正常跳转到按作品寻找区块。
- 聚焦证据：`before-after-390x844.png`（本地 QA 证据）。

### 最终轮

- 同尺寸移动对照与桌面视觉方向对照未发现仍需修改的 P0/P1/P2 问题。
- 预览工具条、参考商品图水印和 Checkout 密码保护均属于已记录的原型环境/素材边界，不是主题视觉实现缺陷。
