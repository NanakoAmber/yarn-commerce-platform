# 正式素材替换清单

> 内部工作清单。合作方提供素材后，按优先级逐项替换并复验日/中/英页面。

## P0：公开演示或上线前必须完成

- 正式品牌名、日文/中文/英文标准写法
- Logo：横版、竖版、单色版、透明底 PNG/SVG
- favicon 与社交分享图
- 首页主视觉原图及移动端裁切版本
- 20 个商品的正式图片图库；当前共有 99 张参考图片需要授权或替换
- 商品正式名称、售价、SKU、库存、材质、重量、长度、推荐针号、护理方式
- 套件包含物、难度、成品尺寸、所需工具、编织图与视频授权
- 日本境内配送范围、运费、免邮门槛、发货时效
- 退换货、取消、瑕疵处理、隐私政策、特定商取引法标示
- 正式客服邮箱、营业时间、LINE 账号、链接和二维码

## P1：合作方对齐后补齐

- 毛线、编织套装、工具与礼物三类入口图
- 包、披肩/围巾、毯子、礼物、一团完成等目的入口图
- 春夏秋冬与节日主题视觉
- 作品过程、手部制作、材质细节与生活场景照片
- 用户作品、评价与发布授权
- 品牌介绍、创作者/团队介绍、选品原则
- 商品图片 alt 文本与三语 SEO 标题/描述

## P2：正式运营阶段持续完善

- 教程、编织图、视频内容库
- 新品与季节专题素材
- 邮件订阅欢迎内容
- LINE 自动回复与客服话术
- 商品搭配、相关推荐与购买数量指南
- 三语术语表、翻译审核人和发布流程

## 建议交付格式

- 图片：优先提供无水印原图；主图建议至少 2000px 长边
- Logo/图标：优先 SVG，同时提供透明底 PNG
- 商品数据：每个商品一行，可用 CSV 或 Google Sheet
- 文案：中文作为内部主版本，同时提供经母语审核的日文发布版；英文作为国际消费者版本
- 文件命名：使用稳定的商品 handle 或 SKU，避免只写“图1”“最终版2”
