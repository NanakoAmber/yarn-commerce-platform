# hitoami 移动首页

模式：Persuade。范围：[Issue #110](https://github.com/hitoami/yarn-commerce-platform/issues/110)。用户在当前会话批准手机视觉并明确要求接入提供的 Logo、重构首页、提交 PR；此前 #109 是探索记录。

构图合同：[手机视觉](110-home-mobile.png)。浅色小屋全幅 Hero、真实 HTML 文案与按钮、左右切换和滑动；下方奶油纸面上只留一只原有动画猫，毛球推进时身后的线缓缓展开。猫活动通道在三个分类图标上方，不能遮挡入口。分类为毛线、编织材料包、成品，使用长绞线、打开的材料盒、针织开衫插画和浅色圆底。Hero 轮播张数与三个分类无关。

手机优先；本轮桌面保持可用，不代表桌面最终验收。继承共享字体和基础 token，局部采用用户批准的低饱和灰棕与奶油纸色，替代旧首页高饱和陶土装饰；不改变商品价格/购买流程的色彩职责。Logo 使用用户包内 02 平面字标原图，保留其品牌色与轮廓，不用文字重画。

品牌介绍位于导航之后、商品精选之前，运营可独立编辑三语文案。现有商品精选与内容入口继续引用 Shopify。生成小屋图与分类插画是品牌氛围素材，不代表实际可售商品、Kit 组成或教程承诺。

运营：每个 Hero slide 独立设置桌面图/手机图、三语标题、说明、按钮、链接和焦点位置；可增删、重排。全页无自动轮播，减少动态设置下显示静态猫。点击分类立即跳转，不等待动画。实装参数和验证结果以代码与 PR 为准。

用户本轮评审追加：默认活动为毛线 → 编织材料包 → 成品，与下方导航同序；运营仍可增删和重排。桌面使用独立横幅，不拉伸手机竖图；标题区保留留白和随文字颜色变化的保护渐变。此为既定视觉内的可读性与素材适配修正。
