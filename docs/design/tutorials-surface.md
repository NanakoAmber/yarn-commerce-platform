## 页面职责

| 页面 | 访客任务与模式 | 已确认的结构 |
| --- | --- | --- |
| 教程首页 | 找到想完成的作品或所需技巧；Operate | 完整作品教程为主、基础技巧为辅；作品图、名称与难度帮助匹配，直接进入教程 |
| 完整作品教程页 | 跟着步骤完成作品；Operate | 成品目标 → 材料准备 → 章节步骤 → 结果检查 → 排错帮助；开始学习和下一步是主要操作 |
| 基础技巧页 | 看懂并完成一个具体动作；Read | 动作近景与分步说明 → 正确结果 → 常见错误；从完整教程进入时支持返回原章节 |

## 内容与交互边界

- 配套 Kit、可单买材料放在准备区作为次要入口，不让购物操作取代学习的主要操作。
- 材料清单明确 Kit 已包含与需自行准备的内容；参考素材不能证明实际配置、库存或兼容性。
- 通用技巧复用 Tutorial，不重复维护每个作品中的相同动作内容；查看或点击下一步不自动创建 Making。
- 沿用 PRODUCT.md 的 MVP 免费、免登录和未来收费规则；本轮不增加付费权限、账号学习进度、订阅或证书。
- 内部原型可用已获准的 Woobles Kit 与 Hoshiami 材料参考，并明确标注；真实内容尚未就绪不阻挡内部结构演示，不据此声称真实可售或获得素材发布许可。
