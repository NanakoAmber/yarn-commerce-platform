# 团队进度页

适用范围：Claude 页面「开店还差什么」及旧 GitHub Pages 入口。依据：Issue #89（2026-09-26 用户确认）。

## 用途与入口

- [开店还差什么](https://claude.ai/artifact/VVNTkXnczkkjBj41Rty4cz) 展示离日本开店还有哪些缺口，并收集团队需求。
- 页面是展示与需求入口，不是任务记录；GitHub Issue 仍是目标、范围、验收和状态的唯一任务记录，PR 保留实现与验证结论。
- 旧进度图退役，`team-map/index.html` 只保留一句迁移说明和新链接；现有 GitHub Pages 发布流程继续承接旧网址。

## 谁维护

- 锦晨负责页面内容与团队访问权限；agent 可按授权协助维护，并依据 GitHub Issue / PR 同步进展。
- 按 Issue #89 的链接提供者说明，新页面目前仅锦晨可见。锦晨需在 Claude 分享菜单中把团队成员加为「参与者」或以上，成员才能提需求；本仓库不管理该权限。

## 需求如何转成 Issue

1. 同事在 Claude 页面提出需求，说明问题与希望达到的结果。
2. 锦晨或 agent 判断值得做的需求，先检查是否已有对应 GitHub Issue：已有则补充，缺少则创建，写清目标、范围和验收标准。
3. 需求转入 Issue 后，任务状态以 Issue / PR 为准，不在展示页另建一套任务记录。

需求被收集不代表已经排期、开始实施或完成。
