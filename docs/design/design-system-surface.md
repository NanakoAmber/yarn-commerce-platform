# 设计系统展示页

2026-09-14 用户确认，Issue #49。本文记录页面职责与建设边界，不是已实现规范，也不代表候选视觉稿获批。

## 用途与范围

- 拟定入口为 Theme 内 `/pages/design-system`，第一版用于内部评审，不作为顾客主导航入口。上线前须核对访问边界；隐藏链接或 noindex 不等于访问控制。
- 访客为设计、开发及运营协作者；以浏览、查找和操作组件为主（Operate），确认组件外观、状态及实际使用方法。
- 展示基础视觉变量、真实共享组件和组合场景，覆盖按钮、商品卡、规格选择、提示、购买模块与教程步骤；只建设近期业务使用的组件，不扩张为通用组件库。
- 商品卡区分 Kit、原材料和成品的信息；展示页与业务页面调用相同源码。交互示例必须隔离真实购物车、订阅和支付，不产生业务写入。
- 覆盖默认、选中、禁用、加载、错误等适用状态，检查手机及中日英文本扩展。AI 评审图内文案使用简体中文；三语效果由实际实现验证。

## 已确认方向

- 以 The Woobles 为新系统的主要视觉与体验参考，Hoshiami 补充原材料零售需求；保留小写 `mewool` 猫标和圆润字形。
- 明亮轻松、大图突出、信息清晰；共用字体、色彩、组件与交互语言，旧版暖纸与细线图谱不作为本轮硬约束。
- 先评审系统视觉，再实现共享组件和展示页；下一阶段精简关键用户路径，并逐步接入业务页面。
- 当前颜色、字体数值和页面构图仍须视觉评审，不将候选参数提前写入 `DESIGN.md`。旧教程三稿不是本轮全局系统的已批准方向。

## 验收原则

- 修改一个共享规则或组件后，展示页和至少一个已接入的实际业务页面同步变化，不依赖重复修改或页面私有覆盖。
- 常用配置与组件代码各有单一来源；展示页不是第二套后台编辑器，也不自动发布变更。
- 沿用 `npm run verify`、适用 detect、1440 / 390 截图打开检查、三语关键路径及独立 finish review；通过后从真实实现更新 `DESIGN.md`。
- Demo 素材来源与发布边界沿用 `PRODUCT.md`。候选图与过程记录只保留本地，获批视觉及必要来源按项目规则归档。
