# 搜索与首页内容区设计约束

来源：[Issue #22](https://github.com/NanakoAmber/yarn-commerce-platform/issues/22)，2026-09-09 用户确认。行为与领域边界以 PRODUCT.md、CONTEXT.md 和作品体验合同为准；本页记录当前视觉约束，不将候选稿写成 DESIGN.md。

## 当前方向

- 手机搜索沿用用户选择的方案 3：作品图文横行，商品两列图卡；暖白纸面、手绘分类、细线图标与克制的陶土色。
- 搜索为独立页面，首页导航不得高亮。搜索栏采用胶囊形，清空 X 与独立滑杆筛选按钮必须明确区分。
- 分类沿用首页「包袋、围巾、家居、玩偶」及对应手绘图标，搜索页增加「全部」；类别按实际内容扩展。
- 作品卡显示名称、一句用途简介、实际购买能力及爱心；商品卡显示名称、简短说明、适用规格、深色适中字重的价格及爱心。难度、时间等仅在适用且有依据时显示。
- 作品与商品的收藏保存于登录账号，跨设备可找回，具有统一入口；不把图标变色或本机临时保存当成功能完成。
- 暂不设计评分、评价数量或收藏人数，不虚构商品事实。

## 搜索与首页分工

- 首页提供精选及分类浏览；统一搜索页用于输入关键词和按条件查找。
- 首次无查询进入搜索页提供输入、分类及可编辑示例关键词；从首页「查看全部」进入时直接显示对应作品浏览，不绕回空入口。
- 简单筛选沿用「全部、有成品、可买材料、仅灵感」，类别不在面板重复。筛选保留关键词，同页展示适用的作品与商品结果，隐藏无命中组。
- 首页作品使用较大图片并复用同一份简介、能力与收藏状态。独立成品区使用 Product 商品卡及商品详情入口，不让作品卡随筛选静默变成商品链接。

## 首页 Hero 的固定边界

- 2026-09-09 已直接核对 Shopify 当前 yarn-commerce-platform/main 主题 189684220217 及最新 origin/main 的 Hero 实现。
- 主标题保持「从喜欢的作品，开始你的手作。」；说明保持「毛线、用量、工具与教程，跟着作品慢慢准备。」；按钮保持「发现作品」。
- 保留「选作品 → 挑毛线 → 找工具 → 看教程」四个手绘节点、毛线连接路径及下方波浪。来源是 sections/yarn-hero.liquid、templates/index.json 和实际引用的 mewool-hero-*-node 图片。
- 本次三个 desktop 方案只比较 Hero 下方搜索、分类、作品与成品区域；不得用旧手提包摄影 Hero、改写标题或重排整个品牌首屏作为候选。
- 桌面候选和检查产物仅在被忽略的本地目录按需保留；选择结果在 Issue 确认后再更新对应约束。实际 Theme 尚未实施本轮搜索或收藏功能。
