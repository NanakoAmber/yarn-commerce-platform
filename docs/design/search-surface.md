# 搜索结果页视觉探索

来源：[Issue #22](https://github.com/NanakoAmber/yarn-commerce-platform/issues/22)。日期：2026-09-08。

状态：2026-09-09 用户选择手机稿 3「清爽图文清单」作为修订基础，并要求先讨论分类筛选、收藏、卡片简介与商品价格排版。最终修订稿尚未批准实施；本文件记录本轮约束，不是成品规范，不更新 DESIGN.md。

## 目标与范围

Surface mode：Operate。让访问者输入一个关键词后直接理解有哪些相关作品、哪些商品可以购买，无须理解内容模型或切换搜索类型。

前三个手机方案中，用户已选择稿 3；当前围绕该稿生成一张修订稿，不实施 Theme。先采用 390 × 844 手机画布决定搜索栏、返回入口与结果层级，复核后再扩展到桌面；此前 1440 × 1024 桌面探索不作为获批方向。

## 已确认行为

- 首页搜索框与导航放大镜使用同一个全站搜索页。
- 搜索结果使用独立页面；首页导航不得高亮。此前视觉稿误画首页选中态，已被用户指出，不是产品决定。手机稿采用返回入口与「搜索」页标题，桌面导航按实际页面判定当前项。
- 输入关键词不继承此前首页的分类或购买方式筛选。
- 相关作品和相关商品同页分组展示，不设类型切换与两套筛选面板。
- 无命中组隐藏；两组均无结果时明确反馈。
- 作品与同款成品可在两组分别出现，各自进入作品详情与商品详情。
- 作品卡区分有成品、可买材料、仅灵感；商品卡显示商品类型与价格。
- 商品匹配自身名称、说明和明确维护的用途；不因作品命中就自动返回通用工具或关联材料。
- 首页仍以作品为中心，保留购买方式筛选；分类「查看全部」继续浏览对应作品。此次画面仅设计关键词搜索态。

## 视觉继承

- 继承当前首页的暖白纸面、陶土色操作、少量奶油黄与自然手作摄影；不更换全站视觉世界。
- 颜色与字体以 DESIGN.md、yarn-design-tokens.css 和当前首页实页截图为参考；手机顶部采用简洁搜索页导航，不照搬桌面导航。
- 参考用户提供的 Airbnb 手机截图中的圆角胶囊搜索栏、细边框、轻阴影和双层文字：关键词「篮子」在上，「作品 · 商品」在下。右侧为清空按钮；下方加入首页手绘分类，卡片增加账号收藏入口，具体确认见下文。不引入旅行条件、地图或底部应用导航。
- 搜索栏点击进入编辑、键盘提交；结果态保持关键词可见，不配大块独立提交按钮。图稿只表示结果态，交互仍待实施验证。
- 三案只改变构图、图片比例、信息密度与组间层级；不以增加功能制造区别。
- 图片内可读文案全部为简体中文。图形标识保留猫与线团意象，评审稿不新增品牌名。

## 选择后的讨论（2026-09-09）

- 用户选择实际显示的手机稿 3：`.impeccable/mocks/22-search/mobile-list-v1.png`，作品图文横行、商品两列图卡。只批准继续沿用其基础方向，待下述内容讨论和修订。
- 用户确认分类按首页基础扩展，以「包袋、围巾、家居、玩偶」及对应手绘图标为基础，增加「全部」。选中分类保留关键词并同时缩小两组结果；本次「篮子」样例选中「家居」。无命中组仍隐藏，两组均无命中时反馈无结果。
- 用户确认作品和商品均可收藏，登录后换手机、电脑仍能找回。修订稿在每张图片右上角放爱心，页头提供「收藏」入口；作品和商品分别保存，不自动连带收藏。此为账号收藏需求，不能只用本机临时状态实现。实际身份与服务接入仍待实施验证。
- 用户明确评分系统暂时不做。
- 用户希望作品卡片直接显示简短介绍，并讨论具体展示信息；名称、简介、购买能力以真实内容为准，难度和时间仅在已核实且适用时显示。
- 商品价格、字号、字体与颜色需要重新审视。当前建议为统一字体、减少粗体与彩色标签、将价格调整到接近标题的字号和深色文字；这仍是设计建议，不是已获批的 DESIGN.md 事实。
